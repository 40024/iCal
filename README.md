
# What and Why 
Whenever making plans, I find myself leaning toward unix cal

Similar to how cal can be used to print a calendar, I wanted a way to print (Date, Weekday) pairs whenever composing plans

iCal prints a new-line by default mapping of weekday abbreviations to day numbers for a month

# Example output
python ical.py 5 2026

Fri 1
Sat 2
Sun 3
Mon 4
Tue 5
Wed 6
...
